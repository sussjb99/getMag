All contributions must be compatible with the GPLv3 license.

---

## How to Contribute

You can contribute in several ways:

- Reporting bugs  
- Suggesting new features  
- Improving documentation  
- Submitting code improvements or fixes  

To get started, simply open an Issue or a Pull Request on GitHub.

---

## Code Contributions

By submitting code to this repository, you agree that:

1. Your contribution is your own original work.  
2. You have the right to submit it under the GPLv3 license.  
3. Your contribution will be released under the same GPLv3 license as the rest of the project.  

Please ensure your code is clear, documented, and follows the general style of the project.

---

## Reporting Issues

If you encounter a bug or unexpected behavior:

1. Check existing Issues to see if it has already been reported.  
2. If not, open a new Issue and include:  
   - A clear description of the problem  
   - Steps to reproduce  
   - Expected vs. actual behavior  
   - Any relevant logs or screenshots  

---

## Pull Requests

When submitting a Pull Request:

- Keep changes focused and minimal  
- Describe the purpose of the change  
- Reference any related Issues  
- Ensure the project builds successfully  

Pull Requests that are too large or unrelated to a specific improvement may be declined.

---

## Code of Conduct

Contributors are expected to behave respectfully and professionally.  
Harassment, abuse, or hostile behavior will not be tolerated.
