Quick Start

  1. Navigate to the first page of your magazine.
  2. Use Region Setup to define your required screen capture area.
  3. Use Configuration Setup to configure parameters.
  4. Use Start Capture to initiate magazine page capturing.
  5. Avoid using Keyboard or Mouse during capturing session until capture is fully completed.
  6. Use PDF Conversion to compile result image files into a single PDF.
  7. View Resulting Output either by viewing individual PNG files from Windows Explorer , or by viewing PDF files Using Browser.
  8. The Location of the Output Directories will be the combination of the location of Output Folder + Magazine Name.

Hotkeys

  • CTRL+ALT+A — About
  • CTRL+ALT+H — Help
  • CTRL+ALT+R — Region Setup
  • CTRL+ALT+C — Configuration Setup
  • CTRL+ALT+P — PDF Conversion
  • CTRL+ALT+S — Start Capture
  • CTRL+ALT+V — View Magazine Folders

Troubleshooting

  • Blank captured images
    Recheck your Capture Coordinates settings.

  • Intermittent missing pages
    Try increasing the Key Delay parameter.

  • Missing pages at the end of the magazine
    Increase the Max Pages parameter.

  • Blurry images
    Capture the images on a computer with a higher‑resolution display.
    • A resolution of 2080×1920 produced excellent results.
    • A resolution of 1680×1050 produced slightly blurry results.

  • Improving clarity during capture
    You can toggle Full Screen Mode using the browser’s F11 hotkey during region setup and the capture process.

  • PDF conversion failures
    Verify that PNG files are being saved in the location specified in Configuration Setup.

  • Mouse cursor appearing in captures
    Move the mouse pointer out of the capture region before initiating the screen captures.

  • Unresponsive modules
    Restart the program.
