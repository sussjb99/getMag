## [1.0.0] - 2025-12-25
### Added
- Initial public release of GetMag.
- Complete open-source codebase licensed under GPLv3.
- Core automation engine for capturing and organizing magazine-style content.
- Configurable workflow system with user-defined automation steps.
- Local-only processing with no cloud dependencies.
- Installer with Acceptable Use Agreement (AUA) for binary distributions.
- Documentation including README, NOTICE, CONTRIBUTING, and AUA files.
